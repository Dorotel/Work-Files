Constitutional Principles

I. Code Quality Excellence

  • Use MVVM Community Toolkit (not ReactiveUI)
  • Enable nullable reference types
  • Centralized error handling
  • Dependency injection for all services

II. Testing Standards

  • Minimum 80% test coverage
  • Critical paths require 95% coverage
  • Follow test naming conventions
  • Integration tests for database operations

III. UX Consistency

  • Use Theme V2 dynamic resources (no hardcoded colors)
  • x:DataType attributes on all UserControls
  • Material Design icons exclusively
  • Cross-platform layout compatibility

IV. Performance Requirements

  • Async/await for all I/O operations
  • Connection pooling configured (MySQL)
  • No blocking UI thread operations
  • Sub-100ms UI response time
